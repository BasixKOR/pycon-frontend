# 세션 목록 다중 연사 사진 표시 설계

## 목적

홈페이지 세션 목록에서 세션 대표 이미지가 없는 경우, 사진이 등록된 모든 연사를 이름과 일치하는 순서로 보여준다.

## 현재 동작

세션 목록은 세션 대표 이미지를 우선 사용한다. 대표 이미지가 없으면 사진이 있는 첫 번째 연사의 사진 한 장만 표시한다. 사용할 이미지가 없거나 이미지 로딩에 실패하면 행사 로고를 표시하며, 행사 로고도 없으면 빈 원형 영역을 표시한다. 연사 이름은 API가 반환한 순서를 그대로 사용한다.

## 확정 동작

1. 세션 대표 이미지가 있으면 현재처럼 대표 이미지 한 장만 표시하고 연사 이름 순서는 변경하지 않는다.
2. 세션 대표 이미지가 없으면 연사를 다음과 같이 안정적으로 정렬한다.
   - 사진이 있는 연사를 API 순서대로 먼저 배치한다.
   - 사진이 없는 연사를 API 순서대로 뒤에 배치한다.
3. 사진이 있는 연사가 한 명 이상이면 해당 연사들의 사진을 정렬된 순서대로 모두 표시한다.
4. 연사 사진은 고정 폭의 2열 격자로 표시한다. 연사가 많아지면 행과 세션 카드 높이가 늘어난다.
5. 사진이 없는 연사를 위한 빈 셀은 만들지 않는다.
6. 연사 이름 칩은 정렬된 연사 순서를 사용하므로, 표시된 사진 순서와 이름 앞부분이 일치한다.
7. 세션 대표 이미지와 유효한 연사 사진이 모두 없으면 기존 행사 로고 대체 동작을 유지한다.
8. 이미지 URL 로딩에 실패하면 기존과 같이 행사 로고로 대체한다. 행사 로고도 없으면 기존 빈 원형 오류 영역을 표시한다.

예시: `A(사진 있음), B(사진 없음), C(사진 있음)`은 사진 `A, C`, 이름 `A, C, B` 순서로 표시한다.

## 구현 범위

변경 대상은 공용 `SessionList`의 세션 카드 이미지와 연사 이름 렌더링이다. API 스키마, 세션 상세 페이지, 시간표, 관리자 및 참가자 포털은 변경하지 않는다.

세션 카드 내부에서 렌더링용 연사 순서와 이미지 목록을 파생한다. 별도의 공용 유틸리티나 외부 의존성은 추가하지 않는다.

## 반응형 동작

사진 격자의 열 수는 화면 크기와 관계없이 2열을 유지한다. 기존 카드의 텍스트 영역이 지나치게 좁아지지 않도록 이미지 영역의 폭을 고정하고, 추가 사진은 아래 행으로 배치한다. 이미지 수에 따라 카드 높이가 늘어나는 것은 허용한다.

## 검증

다음 경우를 확인한다.

- 세션 대표 이미지가 있는 다중 연사 세션
- 대표 이미지 없이 모든 연사가 사진을 가진 세션
- 대표 이미지 없이 일부 연사만 사진을 가진 세션
- 대표 이미지와 모든 연사 사진이 없는 세션
- 연사 사진 URL이 로딩에 실패하는 세션
- 데스크톱과 모바일에서 사진 격자 및 텍스트 영역 배치

저장소에 해당 컴포넌트 테스트가 없으므로 기존 타입 검사와 관련 앱 빌드를 실행하고, 대표 사례를 브라우저에서 확인한다.

## 제외 범위

- 사진과 이름 칩 사이의 클릭 연동
- 연사별 이미지 대체 자산 추가
- 표시할 연사 수 제한 또는 `+N` 축약
- 세션 상세 페이지와 시간표의 연사 표시 변경
